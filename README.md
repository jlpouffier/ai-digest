# AI Digest

What changed in AI, twice a week. Published Sundays and Thursdays.

**Read it: https://jlpouffier.github.io/ai-digest/**

Each edition is 3–4 themed sections built from a hand-curated roster of ~33
sources — frontier labs, individual practitioners, research, tooling, and EU
policy. Where trusted sources disagree about what something means, the digest
says so rather than flattening it. Quiet weeks are allowed to be short.

This repository contains **only the rendered HTML**. The pipeline that produces
it — the source roster, the article summaries, the prompts — runs privately and
is not published here.
